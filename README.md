# ReactJS Rick and Morty Explorer

Proyecto de ReactJS basado en la propuesta **Rick and Morty Explorer**.

## Funcionalidades incluidas

- Aplicación en ReactJS.
- Componentes separados y reutilizables.
- Consumo de la API pública de Rick and Morty.
- Listado inicial de personajes.
- Buscador por nombre.
- Filtros por estado y especie.
- Detalle del personaje en modal.
- Visualización de episodios del personaje.
- Paginación.
- Favoritos con LocalStorage.
- Manejo de carga, errores y resultados vacíos.
- Diseño responsive para móvil, tablet y escritorio.

## Cómo verlo

Abre `index.html` en el navegador.

## Cómo entregar

1. Descomprime el ZIP.
2. Crea un repositorio nuevo en GitHub.
3. Sube todos los archivos y carpetas.
4. Activa GitHub Pages desde Settings > Pages.
5. Entrega el enlace público navegable.
6. Entrega también el enlace del repositorio.
7. Adjunta una captura de pantalla como evidencia.

## Nota

Se usa React mediante CDN para que el proyecto sea fácil de subir directamente a GitHub Pages sin configurar Vite ni ejecutar comandos de instalación.
